## 👋 Sobre mí

Mi experiencia en logística me ayuda a comprender los procesos y necesidades de los negocios. Desarrollo **soluciones corporativas B2B, catálogos interactivos, invitaciones web para bodas y aplicaciones web a medida**.

También he trabajado con **Python, backend, bases de datos, QA y automatización**. Actualmente estudio Ingeniería de Sistemas Computacionales y sigo fortaleciendo mis fundamentos de programación y diseño de software.

## 🚀 Enfoque actual

Construyo plataformas web de alto rendimiento con arquitectura **JAMstack**, usando **Astro**, **TypeScript** y **Tailwind CSS**.

En mis proyectos recientes, el promedio de rendimiento es de **90/100 en Lighthouse Performance**. Uso **Core Web Vitals** como referencia para revisar oportunidades de mejora.

> 💡 **Filosofía de diseño:** Cero código muerto, interfaces limpias, accesibilidad y una experiencia de usuario fluida (*Zero-FOUC*).
